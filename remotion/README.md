## Remotion showcase

Install: `npm install`. Preview: `npm run start`.

`SignalShowcase` is the native composition. `IntegratedShowcase` is the 60-second master and requires the two specialist outputs in `public/assets/`: `hyperframes-showcase.mp4` and `manim-showcase.mp4`. The Colab notebook renders these first, copies them into the Remotion assets folder, and then renders the integrated composition.
